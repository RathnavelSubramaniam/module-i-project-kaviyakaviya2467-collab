# 📈 Stock News Sentiment Analysis using Generative AI

## 📌 Project Overview

This project uses **Generative AI and NLP** to analyze stock market news and classify it as **Positive, Neutral, or Negative**. It helps investors understand market sentiment and make better decisions.

## 🎯 Objective

* Predict the sentiment of stock news.
* Compare different AI models.
* Find the best model for accurate sentiment classification.

## 📂 Dataset

The dataset contains:

* Date
* News Headline
* Stock Prices (Open, High, Low, Close)
* Trading Volume
* Sentiment Label

## 🛠️ Technologies Used

* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Scikit-learn
* TensorFlow / Keras
* Gensim
* Sentence Transformers

## ⚙️ Project Workflow

1. Load the dataset
2. Clean and preprocess the data
3. Perform Exploratory Data Analysis (EDA)
4. Generate text embeddings (Word2Vec & Sentence Transformer)
5. Train Machine Learning and Deep Learning models
6. Evaluate model performance
7. Compare results and select the best model

## 🤖 Models Used

* Random Forest + Word2Vec
* Random Forest + Sentence Transformer
* Neural Network + Word2Vec
* Neural Network + Sentence Transformer

## 📊 Evaluation Metrics

Models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## ✅ Conclusion

The project compares multiple AI models to identify the most accurate approach for stock news sentiment analysis. Transformer-based embeddings and deep learning models provide strong performance for understanding financial news.
